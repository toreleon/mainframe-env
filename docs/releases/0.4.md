# mainframe-env 0.4

Status: Official `0.4.0` release prepared; not tagged, published, or deployed
by this branch

## Release scope

The 0.4 line adds deterministic execution for the pinned COBOL statement and
control families, all 82 intrinsic families, bounded data and pointer state,
typed file and LE effects, JSON/XML processing, condition handling, and
checkpoint/recovery behavior. Checkpoint schema 10 remains backward-readable
with schemas 1 through 9. The approved 16-case GnuCOBOL campaign and focused
condition, recovery, boundary, resource, cancellation, and quantum-identity
matrices are local assurance only.

The 20 compiler-directive rows retain structural recognition and validation;
they are not misreported as executable behavior. Report Writer remains outside
the pinned Enterprise COBOL row denominator because it requires a separately
installed precompiler.

## Parallel integration boundary

The 0.3 through 0.7 subsystem implementations were developed and integrated
in parallel before official product promotion. Consequently this taggable 0.4
source baseline already contains accepted later-minor RACF, dataset/AMS, and
JCL planner work. Their presence does not expand the claims of the 0.4 release
line.

## Differential limitations

The real licensed Enterprise COBOL 6.5 campaign remains exactly 0/153 pending;
GnuCOBOL does not satisfy it. RACF/SAF remains exactly 0/48, dataset/VSAM/AMS
remains exactly 0/36, and the JCL/JES2 licensed differential remains pending
where applicable. Simulations, generated output, historical receipts, and
CardDemo results grant no licensed IBM differential credit.

## Release artifacts

The release retains deterministic, unpublished receipts for
`aarch64-apple-darwin` and `x86_64-unknown-linux-gnu`. Each receipt records the
locked Rust 1.98.0 build inputs, canonical path remapping, binaries,
configuration and migration identities, SBOM, provenance, and checksums bound
to the clean 0.4 source tree. All manifests retain `published=false`.
