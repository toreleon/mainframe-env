## Current work package

DB2-1201 is active. Slice `DB2-1201.reuse-spike` is complete: the checked-in
[reuse spike](../0.12.0-reuse-spike.md) compares 49 representative Db2 forms,
conditionally accepts `sqlparser-rs` only behind an owned bounded AST adapter,
and rejects DataFusion as a production dependency or authority.

Slice `DB2-1201.official-catalog` is complete. It derives an exhaustive typed
174-row identity/descriptor projection directly from the frozen 0.2 catalog;
the generator and focused mutation tests reject denominator, row, identity,
locator, and generated-output drift.

Slice `DB2-1201.lexer` is complete. Exact `sqlparser-rs` 0.63.0 is a private
tokenizer only; all output is immediately converted to bounded owned Db2 token,
span, host-variable, symbol, literal, and diagnostic types. Statement bytes,
raw/owned tokens, token bytes, parenthesis nesting, invalid limits, unsupported
tokens, malformed host variables, and tokenizer failures fail closed. The lexer
is disconnected from execution and grants no recognition credit.

Slice `DB2-1201.ast-primitives` is complete. Bounded owned identifiers,
qualified names, static host references and indicators, built-in/distinct type
syntax, literals, operators, and an append-only acyclic expression arena expose
no third-party types. Constructors enforce name, type-argument, literal, list,
node, reference, and depth limits.

The common/deferred portion of `DB2-1201.catalog-freeze` remains source-blocked.
Slice `DB2-1201.transaction-syntax` is complete. It owns exact typed COMMIT,
ROLLBACK, and SAVEPOINT AST, preserves optional WORK, unit/named/unnamed
savepoint targets, UNIQUE, and retain clauses in either order, and rejects
duplicate clauses, invalid names, malformed operands, extra tokens, and
multiple statements with located diagnostics. It remains disconnected from the
provider transaction route and grants no execution credit.

Slice `DB2-1201.host-reference` is complete. The owned AST and lexer now keep
host-language identifiers separate from SQL identifiers, preserve spelling and
COBOL hyphens, and apply bounded host-name validation without SQL folding.

The statement parser continues in source-reviewed families without a
generic-success or raw-token node. Slice `DB2-1201.dynamic-syntax` is complete
for the declared common static-host subset: PREPARE owns SQLDA naming modes,
attributes with optional indicators, and a non-indicated host source; EXECUTE
owns bounded host-variable/indicator lists or a SQLDA; EXECUTE IMMEDIATE owns a
single non-indicated host source. PL/I expressions, SQL PL variables/arrays,
and multiple-row source buffers fail explicitly and keep SQL rows 0075, 0076,
and 0101 partial with no whole-row recognition credit.

Slice `DB2-1201.expression-parser` is complete for its declared common syntax
substrate. The owned token stream now produces the bounded expression arena for
literals, qualified names, host references and indicators, parameter markers,
scalar calls, casts, prefix arithmetic, arithmetic/concatenation/comparison and
Boolean operators, NULL predicates, and simple/searched CASE. Operator binding
is deterministic, a wildcard is accepted only as a function's sole argument,
and malformed, trailing, unsupported, or over-limit forms fail explicitly. The
NULL predicate rejects parameter markers anywhere in its operand as required by
the pinned source. Scalar fullselects, special registers, durations, arrays,
OLAP/XML/row-change/sequence expressions, broader predicate families, function
resolution, typing, and evaluation remain pending. This syntax substrate grants
no whole-row recognition or execution credit.

The next control step is to declare conflict-isolated parallel slices for the
remaining DB2-1201/DB2-1202 freeze, relational IR, the early DB2-1204 participant
contract audit, and the current DB2-1206 H1/H3 scan before their implementation.
Exact recognition obligations and the common/deferred disposition remain
pending and receive no credit until every row has pinned source review.

## Declared parallel syntax/type slices

The following slices start from commit `06bd397ffda637b668e41fa3c2c7473649c19eeb`.
They are deliberately private and disconnected from execution. Each lane owns
one source module; shared exports, statement-enum integration, changelog, status,
and generated documentation remain manager-owned to keep parallel commits
conflict-free.

| Slice | Catalog/source scope and mandatory slice obligations | Owner and acceptance |
|---|---|---|
| `DB2-1201.select-core-syntax` | SQL row 0121, SELECT. Own one bounded subselect with `ALL`/`DISTINCT`, expression or wildcard select items, named table sources, WHERE, expression GROUP BY, HAVING, expression/integer ORDER BY with direction, OFFSET, and FETCH FIRST/NEXT. Preserve clause order and reject duplicates, missing operands, multiple statements, CTE/set operations/joins/subqueries and every undeclared outer clause. This is partial syntax and grants no row/gate credit. | `mainframe-env-db2::query_syntax`; focused positive/negative/limit tests, package test/check, formatting, diff check, and per-feature seal. |
| `DB2-1201.create-table-common-syntax` | SQL row 0050, CREATE TABLE. Own a bounded named-table definition with named columns, built-in/distinct type syntax, NOT NULL, constant/NULL default, and table PRIMARY KEY/UNIQUE/FOREIGN KEY constraints with referenced columns and the declared common ON DELETE actions. Reject generated/security/period/check/LIKE/AS/materialized/physical clauses and undeclared column options explicitly. This is partial syntax and grants no row/gate credit. | `mainframe-env-db2::create_table_syntax`; focused positive/negative/limit tests, package test/check, formatting, diff check, and per-feature seal. |
| `DB2-1201.declare-cursor-prepared-syntax` | SQL row 0060, DECLARE CURSOR. Own the prepared-statement-name form with bounded cursor/statement identifiers, NO SCROLL/SCROLL, ASENSITIVE/INSENSITIVE/SENSITIVE DYNAMIC/SENSITIVE STATIC, WITH/WITHOUT HOLD, WITH/WITHOUT RETURN and target, and WITH/WITHOUT ROWSET POSITIONING. Reject duplicate/conflicting clauses, invalid modifier combinations, inline SELECT, missing names, extra tokens and multiple statements. This is partial syntax and grants no row/gate credit. | `mainframe-env-db2::cursor_syntax`; focused positive/negative/limit tests, package test/check, formatting, diff check, and per-feature seal. |
| `DB2-1202.common-type-compatibility` | No statement-row claim. Own bounded validated common scalar type shapes and deterministic nullability, numeric/string/binary/datetime assignment and comparison compatibility derived from the pinned data-type and assignment/comparison topics.   CICS source tooling (`runtime operation compatibility set drifted`); its

  `cargo xtask architecture-fast --check` gate proceeds through effect,
  provider-row, durable-storage, and enterprise-authorization guards, then
