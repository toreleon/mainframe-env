# COBOL semantic differential pilot

Run `cargo xtask cobol-differential --cobc /absolute/path/to/cobc --seeds 1..300 --receipt /absolute/path/to/.codex-runs/receipt.json` for a bounded local sweep. `--check` runs seeds 1..9. The receipt path must be in the checkout's `.codex-runs` directory or outside the checkout. A missing or unusable compiler fails the command.

The seeded grammar constructs 2–6 source data items, numeric output companions, edited pictures, alphanumeric moves, and arithmetic. Numeric results are moved to same-picture DISPLAY companions before output; signed companions use a trailing separate sign. The minimizer preserves each output's preceding write. Separate handwritten anchors cover the known issue reports. Anchor results never set `generated_reached`; that field is set only after a generated divergence is minimized and its feature signature matches a cited issue rule. A signature uses de-duplicated verb and storage usage sets, scale buckets (0, 1–9, and 10+), edited picture features, division and rounding flags, and the outcome kind. Classes with the same signature and issue attribution are counted together, with one minimized representative. Unmatched divergences are product defect candidates. Compiler rejections are generator bugs and are counted separately; rejection above 20% calls for a grammar correction. The checked-in allowlist starts empty and requires a documented reason for each entry.

The reference is built with `cobc -x -std=ibm -free -fbinary-truncate`. `-fbinary-truncate` makes ordinary binary items truncate to their PICTURE digits, emulating IBM's default TRUNC(STD), which the product models; without it, GnuCOBOL wraps binary storage and reports false divergences. The process limits are ten seconds and 64 KiB of output per child process. GnuCOBOL is a development reference, not IBM authority. This campaign grants zero licensed conformance credit. Treat new differences as leads for issue triage.
