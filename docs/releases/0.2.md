# mainframe-env 0.2

Status: Implementation candidate (`0.2.0`); not released

## Candidate scope

The 0.2 line adds reviewed official coverage catalogs and six independent
evidence gates, generated semantic/program/route registries, signed versioned
application-package sections, generic package-installed Db2 schemas, installed
batch controllers, and subsystem-owned host ABI source libraries.

Production application hardcode and application string-dispatch counts are
zero. CardDemo remains an external conformance workload and is not shipped as
product data or behavior. Generated/catalog presence grants no official
compatibility numerator; all official gate numerators remain zero until their
required semantic and licensed differential evidence exists.

## Upgrade and rollback

All five 0.2 migration contracts are additive and non-destructive. Application,
Db2 catalog, batch controller, host ABI, and generated registry rollback retain
or regenerate a complete prior generation without selecting partial state.

## Release boundary

This candidate may be reviewed through the implementation pull request. It is
not tagged, published, deployed, merged, or advertised as released by the 0.2
implementation workflow.
