## Current work

CIC-901 starts with a registration-closure admission helper in the existing
`mainframe-env-host-api` owner. `OfficialHandlerUnit` borrows the generated
catalog, selects an exact baseline/subsystem/unit, and requires each official
identity to resolve to an explicit ready handler in the shared immutable
registry. It rejects an unknown/empty unit, missing handlers, and unready
handlers with bounded deterministic diagnostics. Its publication helper checks
closure before using the existing monotonic publisher; no second registry or
publication authority is introduced.

Internal tests enumerate every single application-handler omission and every
single unready handler. Additional cases cover the pinned 263-identity scope,
out-of-scope/custom replacements, input order, duplicates, failed publication
without mutation, stale generations, held snapshots, and reuse across generated
units. These are registration tests, not command implementations or official
behavioral Conformance IR bindings.
