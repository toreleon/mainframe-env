# mainframe-env 0.3

Status: Official `0.3.0` GitHub Release published on 2026-09-02

## Release scope

The 0.3 line introduces the shared product-neutral Conformance IR, typed row
specifications and obligations, bounded registries, deterministic shards and
cache identities, replayable verdicts, and verdict-derived ledgers. It closes
recognition and validation for all 173 pinned COBOL structure and type-system
rows, including directives, declarations, procedure statements, bounded data
layouts, intrinsic signatures, special registers, malformed-input recovery,
and compatibility with the immutable 0.1.1 artifact fixture.

Execution, condition, recovery, and differential credit outside those accepted
0.3 gates is not implied by catalog presence or by broad CardDemo tests.

## Parallel integration boundary

The 0.3 through 0.7 subsystem implementations were developed and integrated
in parallel before official product promotion. Consequently this taggable 0.3
source baseline already contains accepted later-minor COBOL execution, RACF,
dataset/AMS, and JCL planner work. Those files are present for integration
truthfulness; they do not expand the claims of the 0.3 release line.

## Differential limitations

No licensed IBM differential campaign is reported complete. Enterprise COBOL
remains exactly 0/153, RACF/SAF remains exactly 0/48, dataset/VSAM/AMS remains
exactly 0/36, and the JCL/JES2 licensed differential remains pending where
applicable. Local simulations, GnuCOBOL checks, generated output, historical
receipts, and CardDemo results grant no licensed differential credit.

## Release artifacts

The GitHub Release publishes deterministic evidence archives for
`aarch64-apple-darwin` and `x86_64-unknown-linux-gnu`. Each receipt records the
locked Rust 1.98.0 build inputs, canonical path remapping, binaries,
configuration and migration identities, SBOM, provenance, and checksums bound
to the clean 0.3 source tree. The immutable candidate manifests retain their
original `published=false` field; external publication is recorded by GitHub.
