# Randomized COBOL differential testing v1

Run `cargo xtask cobol-differential --check --cobc /usr/bin/cobc --receipt /absolute/path/to/.codex-runs/smoke.json` for the fixed seeds 1..9 smoke. Omitting `--check` also selects that small default. The smoke asserts nine generated programs, rather than elapsed time; ten separate handwritten anchors also run, keeping the total below 50 programs. A missing or unusable compiler fails the command. Ordinary unit tests do not launch reference campaigns.

Larger sweeps require explicit `--sweep --seeds a..b`, with an inclusive budget of at most 300 generated programs. For example, run `cargo xtask cobol-differential --sweep --cobc /usr/bin/cobc --seeds 1001..1025 --receipt /absolute/path/to/.codex-runs/sweep.json`. Run campaigns sequentially. Each failing generated program prints its exact seed, including cases grouped with an earlier representative. Reproduce it with `--sweep --seeds SEED..SEED`. The receipt must have a fresh absolute path outside the checkout or under its `.codex-runs` directory, including evidence subdirectories.

The deterministic bounded grammar constructs 2–6 source data items and at most four operations. Numeric PICTUREs have at most 18 digits, signed or unsigned, with integer and scaled forms in DISPLAY, COMP, COMP-3, COMP-5 and BINARY storage. ADD, SUBTRACT, MULTIPLY, DIVIDE and COMPUTE include ROUNDED and scoped ON SIZE ERROR variants; handlers move zero to the result. MOVE destinations include insertion commas, blanks, zeroes and slashes, zero suppression, floating currency and signs, and CR/DB suffixes. Numeric results move to same-picture DISPLAY companions before output; signed companions use a trailing separate sign. Edited results display their literal character representation. Whitespace and sign characters remain significant in comparisons.

The minimizer delta-debugs statement and declaration chunks, then reduces numeric PICTURE repeat counts and expanded edited widths, repeating until stable. Numeric storage and its DISPLAY companion shrink together. Candidates retain legal VALUE widths, initialized output, and the observed difference and terminal outcome; both compilers must still accept them. Rejected compile cases retain the original source and diagnostic rather than claiming a minimized runtime result.

Receipts classify observed differences as known mainframe-env defects, product defect candidates, or allowlisted GnuCOBOL-versus-IBM differences. Known-issue attribution is a feature-based triage lead, not proof of the root cause. Separate anchors never set `generated_reached`. Generated reach is recorded only after minimization matches an issue rule. Signatures group verb and usage sets, scale buckets, editing features, division, rounding and outcome; one representative is retained per class. Reference compiler rejection is a generator bug, is reported with its seed and diagnostic, and fails the command after saving the receipt. Product rejection of reference-accepted source is a product defect candidate, with the reference observation retained.

The checked-in `conformance/spec/cobol-differential-allowlist.json` starts empty. Every entry requires a unique nonempty `signature`, a nonempty `reason`, and a `citation` identifying a pinned IBM Enterprise COBOL 6.5 Language Reference catalog topic, for example `https://www.ibm.com/docs/en/SS6SG3_6.5/lr/ref/rlddepic.html`. The tool validates all entries before launching a compiler, including unmatched entries. Missing, unrelated or unknown citations fail the tool. An allowlisted difference takes precedence over a feature-based issue guess; new entries require source review of the documented IBM behavior.

The reference is built with `cobc -x -std=ibm -free -fbinary-truncate`. `-fbinary-truncate` makes ordinary binary items truncate to their PICTURE digits, matching the intended IBM TRUNC(STD) comparison. The reference's harmless `_FORTIFY_SOURCE` stderr warning does not change stdout/return-code comparison. Each child process has a ten-second limit and a 64 KiB output bound. GnuCOBOL is a development reference, not an IBM oracle, and receipts grant zero licensed conformance credit.

The grammar follows catalog baseline `ibm-enterprise-cobol-6.5-2026-05-31`: the PICTURE clause row `data-description-clauses:0008` (`SS6SG3_6.5/lr/ref/rlddepic.html`) and the ADD, SUBTRACT, MULTIPLY, DIVIDE and COMPUTE procedure-statement rows. Offline source review must use `conformance/tools/ibm_docs.py search` and `read`; unavailable retained bodies or TOCs must be reported, without refreshing the cache during ordinary review.
