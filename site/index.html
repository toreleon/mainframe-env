01 / The project

Familiar systems.
Deliberate boundaries.

mainframe-env combines a COBOL compiler and execution kernel with implementations of mainframe subsystem contracts. Each layer has a clear responsibility and an explicit scope.

[ 01 ]

A deterministic core

Compilation and execution semantics stay deterministic. I/O, scheduling, persistence, and transport live behind owned contracts.

COBOL / compiler / interpreter
[ 02 ]

A composed environment

CICS, JCL/JES, datasets, RACF/SAF, z/OSMF, Db2, IMS, MQ, and spool fit into one application and provider architecture.

Contracts / providers / stores
[ 03 ]

Evidence with provenance

Versioned catalogs, fixtures, and verification gates make scope inspectable. Local and modeled results remain distinct from licensed IBM differential evidence.

Conformance / fixtures / gates

02 / Architecture

One coherent path
from source to state.

Application entry points compose the system. Kernels own compilation and execution. Providers and stores implement the contracts that connect the environment.

  1. Entry pointsHTTP · CLI · z/OSMF

    Application composition
    and admission

  2. KernelsCompile · Run · Batch

    Compiler, interpreter,
    and batch execution

  3. ContractsExecution · Host · Store

    Owned interfaces
    and explicit effects

  4. ImplementationsProviders · Durable stores

    Subsystem behavior
    and persistence adapters

↳ Semantic work stays deterministic; external effects cross an owned boundary.

04 / Getting started

Start with a
small program.

With repository access, install the pinned toolchain and run the included fixed-format COBOL fixture from your checkout.

Rust 1.98.0Fixture: HELLO.cbl
View repository ↗
Compile & run bash
# Compile the included COBOL fixture
cargo run --quiet -p mainframe-env-cli \
  --bin mainframe-env -- \
  compile conformance/0.1/fixtures/cobol/HELLO.cbl \
  --format fixed

# Execute it
cargo run --quiet -p mainframe-env-cli \
  --bin mainframe-env -- \
  run conformance/0.1/fixtures/cobol/HELLO.cbl \
  --format fixed
