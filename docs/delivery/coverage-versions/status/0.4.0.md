## Decisions and risks

- Extend the accepted compiler HIR and the single deterministic Core-MIR
  interpreter; no second COBOL parser, invocation path, conformance IR, or
  coverage ledger is permitted.
- Providers, clock, locale inputs, and asynchronous I/O remain explicit typed
  effects outside the interpreter kernel. Runtime limits and failure categories
  use the accepted execution contracts.
- The frozen decimal/IEEE spike selected exact `dec = 0.4.11` and deterministic
  software `libm = 0.2.16`; the reviewed gap matrix is recorded in
  `0.4.0-decimal-ieee-spike.md`. IBM-visible PICTURE, representation,
  intermediate precision, alias, and SIZE ERROR rules remain owned adapters.
- Execution, condition, recovery, and differential credit must be emitted as
  obligation-level verdicts extending the accepted 0.3 row specifications.
  Catalog presence and broad workload success grant no credit.
- Licensed Enterprise COBOL 6.5 oracle work remains honestly pending until a
  version-pinned compiler/runtime receipt is available. This does not block
  local implementation or non-differential gates.

External blocker: the required licensed Enterprise COBOL 6.5 compiler/runtime
environment and its version-pinned receipt are unavailable, so no differential
verdict can honestly pass. Local semantic breadth work remains actionable and
continues independently; the external environment is not yet the sole blocker.
