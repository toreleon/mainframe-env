# mainframe-env 0.5.0 — Complete RACF command language and SAF

Status: **Implementation candidate — pass with licensed differential pending**
Start gate: 0.2 official catalog, coverage, identity, and store contracts frozen
Completion dependencies: 0.2.0
Estimate: 16–24 engineer-months

## Outcome

Implement the 34 pinned RACF command families and 14 RACROUTE request types over
one generic, schema-versioned security authority.

## Owned scope

- Complete user, group, dataset, general-resource, connection, list/search,
  alter/delete, SET/SETROPTS, subsystem, RRSF, certificate/keyring, distributed
  identity, and operational command behavior.
- Model profile templates/segments, CDT classes, group hierarchy/authority,
  conditional access, UACC, security levels/labels/categories, PROGRAM control,
  password/passphrase/MFA policy, and auditing.
- Model ACEE creation/deletion/nesting, tokens, AUTH, AUDIT, DEFINE, DIRAUTH,
  EXTRACT, FASTAUTH, LIST, SIGNON, STAT, TOKENBLD/MAP/XTR, VERIFY, and VERIFYX.
- Implement exact SAF/RACF return/reason codes, RACLIST/cache refresh, logging,
  delegation, restart, database variation, and fail-closed behavior.

## Parallelization

Command families can be divided by profile class after the transaction and
authorization contracts freeze. SAF/ACEE work can run beside command-language
work. Cache/SETROPTS integration is serialized with the security authority.

0.5 is parallel-safe with 0.3 COBOL, 0.6 dataset, and 0.7 JCL. It must finish
before JES and CICS security completion.

## Exit gate

- 34/34 command families and 14/14 RACROUTE types complete all applicable
  gates.
- Supplied and installation-defined classes use schema/configuration data, not
  application branches.
- Exact access, group, UACC, conditional, label, cache, token, and audit
  matrices pass.
- Credential, certificate, token, and audit secrets remain bounded/redacted.
- Restart/recovery and the independent bounded reference-simulation gates pass.
- Licensed z/OS 3.2 RACF/SAF differential remains explicitly 0/48 pending under
  the user-approved 2026-09-01 completion policy. It cannot receive credit from
  simulation and moves to the 0.17 `release-certify` hard gate.

## Non-goals

- Replacing every third-party external security manager.
- z/OSMF protocol translation, which belongs to 0.11.
