# mainframe-env 0.5

Status: Official `0.5.0` GitHub Release published on 2026-09-02

## Release scope

The 0.5 line adds the complete pinned RACF/SAF surface: all 34 command families
and 14 RACROUTE rows recognize, validate, execute, report conditions, and
recover through one typed provider authority. It includes generated class and
command catalogs, profile and access semantics, RACLIST/cache behavior,
ACEE/token state machines, credential and phrase policy, MFA, certificate and
keyring references, distributed identity mappings, RRSF state, bounded audit
redaction, durable replay, restart reconciliation, migration, and rollback.

The independent pure-state reference model, property/metamorphic tests, and
mutant checks are development assurance only. Secret and cryptographic material
crosses stable boundaries only as owned references or redacted outcomes.

## Parallel integration boundary

The 0.3 through 0.7 subsystem implementations were developed and integrated
in parallel before official product promotion. Consequently this taggable 0.5
source baseline already contains accepted later-minor dataset/AMS and JCL
planner work. Their presence does not expand the claims of the 0.5 release
line.

## Differential limitations

The real licensed z/OS 3.2 RACF/SAF campaign remains exactly 0/48 pending; the
reference model cannot satisfy it. Enterprise COBOL remains exactly 0/153,
dataset/VSAM/AMS remains exactly 0/36, and the JCL/JES2 licensed differential
remains pending where applicable. Simulations, generated output, historical
receipts, and CardDemo results grant no licensed IBM differential credit.

## Release artifacts

The GitHub Release publishes deterministic evidence archives for
`aarch64-apple-darwin` and `x86_64-unknown-linux-gnu`. Each receipt records the
locked Rust 1.98.0 build inputs, canonical path remapping, binaries,
configuration and migration identities, SBOM, provenance, and checksums bound
to the clean 0.5 source tree. The immutable candidate manifests retain their
original `published=false` field; external publication is recorded by GitHub.
