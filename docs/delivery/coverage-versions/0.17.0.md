# mainframe-env 0.17.0 — Licensed IBM differential certification

Status: **Proposed**
Start gate: full z/OSMF profile and cross-resource semantics accepted
Completion dependencies: 0.11.0, 0.16.0
Estimate: 12–20 engineer-months

## Outcome

Certify the unchanged 1.0 candidate against licensed, pinned IBM environments
and rehearse the complete evidence, migration, rollback, and release process.

## Owned scope

- Pin IBM product levels, APAR/PTF/service state, configuration, locale/CCSID,
  topology, test data, authority model, and environment receipts.
- Run differential oracles for COBOL, JCL/JES, RACF/SAF, datasets/VSAM/AMS,
  CICS API/SPI/FEPI, z/OSMF, Db2, IMS, MQ, and cross-resource journeys.
- Run the deferred 0.5 RACF/SAF campaign for all 34 command-family and 14
  RACROUTE rows; independent simulation is development assurance and supplies
  no licensed differential credit.
- Consume the 0.4 COBOL handoff at differential 0/153 pending and run its real
  licensed Enterprise COBOL 6.5 153-row campaign; the approved GnuCOBOL
  reference campaign is not an IBM oracle receipt and cannot increment the
  differential numerator.
- Consume the 0.6 dataset/VSAM/AMS handoff at differential 0/36 pending and run
  its real licensed 36-row campaign; the 0.6 reference simulation is not an
  oracle receipt and cannot increment the differential numerator.
- Normalize results only at documented nondeterministic fields; preserve exact
  inputs, outputs, traces, timing bounds, diagnostics, and source identities.
- Resolve every mismatch as an implementation defect, baseline correction, or
  explicit excluded row; the final pinned inventory accepts no unsupported row.
- Rehearse clean build, migration, backup/restore, upgrade, rollback, evidence
  assembly, SBOM/provenance, load, soak, failure, and release operations.

## Parallelization

Per-subsystem licensed oracle campaigns can run in parallel against the same
candidate source and environment schema. Mismatch fixes merge one at a time and
invalidate affected receipts. Final cross-subsystem replay, evidence digest,
and release rehearsal are serialized on one unchanged source identity.

## Exit gate

- Every official inventory row in the pinned programming scope is complete at
  all applicable gates; no partial or unsupported row is accepted.
- All licensed differential campaigns pass with reviewed environment receipts,
  result artifacts, normalizers, and source/artifact digests.
- The deferred RACF/SAF differential advances from 0/48 pending only through a
  real pinned licensed z/OS 3.2 campaign receipt accepted by the shared runner.
- The deferred 0.4 COBOL campaign passes 153/153 on the unchanged candidate
  with a reviewed licensed Enterprise COBOL 6.5 receipt; GnuCOBOL remains zero-
  credit development assurance.
- The deferred 0.6 dataset/VSAM/AMS campaign passes 36/36 on the unchanged
  candidate with a reviewed licensed z/OS 3.2 receipt.
- Architecture, de-hardcoding, dependency, license, advisory, fuzz, load, soak,
  recovery, migration, backup/restore, and rollback gates pass.
- An independent reviewer can reproduce the evidence package and release
  rehearsal from the pinned inputs.
- The exact source proposed for 1.0 completes rehearsal without code changes.

## Non-goals

- Whole IBM ecosystem parity beyond the explicitly pinned programming surface.
- Publishing or tagging 1.0; that remains a separately authorized 1.0 action.
